## What's new in 0.3.0

- **Import and export.** Import collections, environments and requests from Postman (v2.0 and v2.1), OpenAPI 3.x and Swagger 2.0 (JSON or YAML), cURL commands, HAR files, Insomnia v4 exports and Bruno collection folders. A preview lists what was converted, skipped or lost before anything is written. Export to Postman v2.1, OpenAPI 3.0 (inferred), Insomnia v4 and Bruno (zip). Secret values are never exported.
- **Advanced authentication.** Besides Basic, Bearer and API key, a request can now use OAuth 2.0 (client credentials, authorization code with PKCE, password, automatic refresh), JWT signing (HS, RS and ES algorithms), Digest and AWS Signature v4. Client certificates (mTLS) are configured per host and kept outside the workspace.
- **Response tools.** A Timing tab (DNS, connect, TLS, waiting, download) and the HTTP version used on every response, which you can choose per request (HTTP/3 is experimental). A Diff tab compares the response with the previous one or a pinned baseline. "Generate code" turns a request into cURL, JavaScript, Python, C#, PowerShell or Go, and "Decode JWT" inspects a token.
- **Scripts use `yaapic`.** The script API namespace is now `yaapic` (`yaapic.environment.set(...)`) in JavaScript and Lua; `pm` is no longer defined, so rewrite existing scripts or paste them through the new "Paste Postman/Bruno..." dialog, which converts them and lists what it could not. A catalogue of 22 snippets is available from the Snippets menu next to the script editor and in completion.
- **Updates check more often.** With "Check for updates automatically" on, Yaapic checks at every launch and then every hour while it runs, instead of once a day. "Check for updates" stays available in Settings and the command palette.

## Nouveautés de la 0.3.0

- **Import et export.** Importez des collections, des environnements et des requêtes depuis Postman (v2.0 et v2.1), OpenAPI 3.x et Swagger 2.0 (JSON ou YAML), des commandes cURL, des fichiers HAR, des exports Insomnia v4 et des dossiers de collection Bruno. Un aperçu liste ce qui a été converti, ignoré ou perdu avant toute écriture. Exportez vers Postman v2.1, OpenAPI 3.0 (déduit), Insomnia v4 et Bruno (zip). Les valeurs secrètes ne sont jamais exportées.
- **Authentification avancée.** En plus de Basic, Bearer et clé d'API, une requête peut désormais utiliser OAuth 2.0 (client credentials, code d'autorisation avec PKCE, mot de passe, renouvellement automatique), la signature JWT (algorithmes HS, RS et ES), Digest et AWS Signature v4. Les certificats clients (mTLS) se configurent par hôte et restent en dehors de l'espace de travail.
- **Outils de réponse.** Un onglet Timing (DNS, connexion, TLS, attente, téléchargement) et la version HTTP utilisée sur chaque réponse, que vous pouvez choisir par requête (HTTP/3 est expérimental). Un onglet Diff compare la réponse à la précédente ou à une référence épinglée. « Générer le code » transforme une requête en cURL, JavaScript, Python, C#, PowerShell ou Go, et « Décoder un JWT » inspecte un jeton.
- **Les scripts utilisent `yaapic`.** L'espace de noms de l'API de script est désormais `yaapic` (`yaapic.environment.set(...)`) en JavaScript et en Lua ; `pm` n'est plus défini : réécrivez vos scripts existants ou collez-les dans la nouvelle boîte « Coller Postman/Bruno... », qui les convertit et liste ce qu'elle n'a pas pu convertir. Un catalogue de 22 extraits est disponible dans le menu Extraits à côté de l'éditeur de script et dans l'autocomplétion.
- **Recherche de mises à jour plus fréquente.** Avec « Rechercher les mises à jour automatiquement » activé, Yaapic recherche à chaque lancement puis toutes les heures tant qu'il tourne, au lieu d'une fois par jour. « Rechercher des mises à jour » reste disponible dans Paramètres et dans la palette de commandes.
