# P-11: WinUI: Settings dialog

Status: todo
Platform: windows
Depends on: P-08, P-10

## Goal

A Settings dialog; the existing "Updates and about" content becomes one of its sections. It has a language picker with the restart
notice, accent swatches with a live preview, a custom colour field and a "Windows accent" option.

## Acceptance criteria

- [ ] Opened from the menu and the palette; keyboard and screen-reader friendly (names, focus order).
- [ ] Screenshot in `docs/screenshots/settings`.
